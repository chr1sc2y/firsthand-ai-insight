模型发布与开源

腾讯开源 Hy4 预览版，770B 参数模型

高

事实

  • 腾讯发布并开源 Hy4 预览版，总参数 770B，每个 token 激活 49B，上下文窗口 1M。 S001
  • 该模型采用 Gated DSA 注意力和 iHC 残差路径，基于 Apache 2.0 开源。 S001
  • 内部盲测显示，Hy4 预览版在工程任务上略优于 GLM-5.3 和 Kimi K3。 S001

分析. 这是中国主要实验室的一次重要开源发布，可能加剧开放权重模型领域的竞争。

影响. 开发者可能获得一个高性能、大上下文窗口的开放模型，减少对专有 API 的依赖。

不确定性. 独立基准尚未可用；性能声明基于腾讯内部评估。

智谱发布 GLM-5.3 权重并修复 Flash 配置问题

高

事实

  • 智谱在 HuggingFace 和 ModelScope 上发布了 GLM-5.3 模型权重。 S001
  • GLM-5.3 基于 GLM-5.2 相同基础，通过后训练改进，特别是在智能体编码和网络防御方面。 S001
  • 智谱修复了 GLM-5.3-Flash 中导致智能体性能下降的参数配置问题，并向受影响用户提供使用额度。 S001

分析. 快速修复和补偿表明生产级 AI 服务可靠性的重要性。

影响. GLM-5.3-Flash 用户应重试之前表现不佳的工作流。

不确定性. 配置问题的具体性质未披露。

高

高

事实

分析. 这些改进解决了代理编码工具中的常见痛点，使其更高效、更用户友好。

影响. 使用 Claude Code 的开发者将受益于更快的启动和更低的资源占用。

不确定性. 无重大不确定性。
