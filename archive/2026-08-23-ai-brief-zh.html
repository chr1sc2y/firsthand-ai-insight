模型发布与定价

DeepSeek 推出多模态视觉模型

高

事实

  • DeepSeek 发布了 DeepSeek-V4-Flash-Vision-Exp，一个多模态视觉理解模型，可在其 API 平台上使用。 S004
  • 该模型的纯文本能力与 DeepSeek-V4-Flash 相当，多模态代理能力接近 Opus-4.8。 S004
  • 它支持 Chat Completions、Messages 和 Responses API 格式，上下文长度为 1M，最大输出为 384K tokens。 S004
  • 定价与 DeepSeek-V4-Flash 一致，并提供免费的 Files API 允许图像上传以节省带宽。 S004

分析. 此次发布表明 DeepSeek 积极进军多模态和代理能力领域，旨在与领先的闭源模型竞争，同时保持有竞争力的定价。

影响. 开发者现在可以低成本利用高能力多模态模型，可能加速基于视觉的 AI 应用的采用。

不确定性. 确切的基准比较和实际性能尚未独立验证。

OpenAI 将 GPT-5.6 Sol API 价格下调超过 20%

高

事实

  • OpenAI 宣布 GPT-5.6 Sol API 价格下调超过 20%，有效期为三个月。 S004
  • 此次降价适用于 API 用户和按量付费的 Codex 信用额度，但不适用于 Pro、Plus 或 Business 订阅计划。 S004

分析. 此举可能是对更便宜的开源权重模型和竞争对手的回应，旨在留住开发者。

影响. 使用 GPT-5.6 Sol 的开发者未来一个季度可享受更低成本，可能影响预算分配。

不确定性. 确切百分比和持续时间已确认，但长期定价策略未知。

代理工具与开发者体验

Codex 使用异常与银行重置

高

事实

  • Codex 负责人 Tibo 报告称，部分用户本周缓存命中率较差，可能解释了使用量消耗更快的原因。 S020
  • Tibo 表示，使用 sub2api（将订阅转换为共享 API）的用户会被欺诈系统标记，但一些用户否认使用。 S004
  • Codex 达到 2000 万活跃用户，并向所有付费 ChatGPT Work 和 Codex 用户发放了银行重置。 S004 S026

分析. 使用异常和随后的重置表明 Codex 在扩展过程中遇到成长烦恼，潜在滥用和技术问题影响用户信任。

影响. 付费用户获得一次性重置，但需要持续监控以确保公平使用和系统稳定性。

不确定性. 缓存命中率问题的根本原因仍在调查中。

编码代理的远程控制功能

高

事实

  • Anthropic 改进了 Claude Code Remote Control，允许用户从移动设备启动会话并自动恢复断开的连接。 S004
  • Google Antigravity 推出了 Remote Control，允许从浏览器和移动设备访问活动会话，首先向 Ultra 订阅者推出。 S004

分析. 两家主要厂商都在增强远程控制能力，反映出对灵活、随时随地的编码代理管理的需求。

影响. 开发者现在可以随时随地管理编码会话，提高生产力和响应能力。

不确定性. 完整功能集和可靠性尚未独立评估。

llm 0.33 发布，改进密钥处理和模板组合

高

事实

  • llm 0.33 升级到 OpenAI Python 库 3.x，并将 HTTP 客户端切换到 httpx2。 S002
  • 嵌入命令现在接受 --key，Python 方法支持 key= 参数。 S002
  • llm prompt -t 可以重复使用以组合模板，实现模型配置复用。 S002

分析. 这些改进简化了 LLM 工具的开发者体验，使其更灵活并适应现代 API 变化。

影响. llm 用户可以从更好的密钥管理和更可组合的提示中受益，减少复杂工作流中的摩擦。

不确定性. 未报告已知问题。
