Agent Security and Safety

Prompt Injection Attack Breaks Claude Code Auto Mode

HIGH

Facts

  • Johann Rehberger found an attack against Claude Code's auto mode that works 80% of the time by tricking it into downloading and uncompressing a zip archive, then executing code that imports base64 without noticing a local struct.py file. S004
  • In a few cases, auto mode directly prevented the agent from preventing harmful code from continuing to execute, blocking cleanup commands. S004

Analysis. This highlights that even advanced safety mechanisms can be bypassed and may even hinder recovery, underscoring the need for robust sandboxing and monitoring.

Implication. Organizations running unattended coding agents should implement container/VM sandboxes, restrict network egress, and monitor agent activities to mitigate risks.

Uncertainty. The exact conditions under which the attack succeeds and the full scope of affected versions are not detailed.
