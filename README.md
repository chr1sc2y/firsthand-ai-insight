# Firsthand AI Insight

Standalone GitHub Pages host for the AI interpretation briefs generated by
[`firsthand-ai-digest`](https://github.com/chr1sc2y/firsthand-ai-digest).

- Custom domain: `insight.ai.prov1dence.top`
- Root path: displays the latest English brief
- Brief files: `archive/*.html`

## Repository layout

| Path | Purpose |
|------|---------|
| `index.html` | Latest English brief (served at `/`) |
| `archive/` | Published brief HTML and `index.json` |
| `data/source-packs/` | Raw source material used during brief generation |
| `staging/ai-briefs/` | Pre-publish brief drafts (gitignored) |
| `CNAME` | Custom domain for GitHub Pages |

Root keeps only site metadata and the live Pages artifact. Codex automation
should write drafts to `staging/ai-briefs/` and source material to
`data/source-packs/` instead of the repository root.

Do not edit generated brief files here by hand. Update the source brief in the
main digest repository and run `scripts/sync_insight_site.py`.
